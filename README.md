## Projects

### Data engineering

- [**air-quality-pipeline**](https://github.com/chtanzeel/air-quality-pipeline): scheduled Airflow pipeline that loads hourly air quality data for five Pakistani cities from a public API into Postgres incrementally, using watermarks. Modelled and tested with dbt, it runs with one `docker compose up`. It backfilled 183,920 rows in under four minutes, re-runs change nothing, and its quality checks caught a 60-hour upstream data outage.
- [**flight-lakehouse**](https://github.com/chtanzeel/flight-lakehouse): medallion pipeline on PySpark and Delta Lake processing 3M flight records, with data quality quarantine, reconciliation checks, CI on two table formats and a Databricks/AWS deployment guide.

### Machine learning experiments
